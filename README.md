# 🏦 NovaBank 2.0: Tech Vision 2030
> **Proyecto Final de Consultoría Tecnológica - ITSE**

Bienvenido al repositorio oficial de **NovaBank 2.0**, la propuesta de transformación digital e infraestructura Cloud-Native diseñada para modernizar los servicios financieros de NovaBank Global S.A.

---

## 📌 Resumen del Proyecto

El proyecto **Tech Vision 2030** aborda la obsolescencia de los sistemas bancarios tradicionales, eliminando cuellos de botella en el proceso de Onboarding digital y mejorando la escalabilidad transaccional. 

### 🚀 Pilares Clave de la Solución:
* **Onboarding Ultra Rápido:** Reducción del tiempo de apertura de cuenta de 72 horas a **menos de 180 segundos** mediante verificación biométrica facial y lectura OCR.
* **Arquitectura Cloud-Native:** Despliegue en **Amazon EKS (Kubernetes)** y mensajería distribuida con **Apache Kafka** para procesar más de **5,000 transacciones por segundo (TPS)**.
* **Evaluación Crediticia con IA:** Motor de análisis predictivo (XGBoost) para pre-aprobación de créditos en **menos de 2 segundos**.
* **Ciberseguridad Avanzada:** Arquitectura **Zero Trust**, cifrado mTLS, módulos HSM Thales y cumplimiento estricto de **PCI-DSS 4.0**.
* **Viabilidad Financiera:** Presupuesto de **$1.39M USD**, ROI proyectado del **276.57%** a 3 años y recuperación de la inversión (Payback) en **14 meses**.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React / Next.js / Tailwind CSS
* **Despliegue & Hosting:** Vercel (CI/CD conectado a GitHub)
* **Backend & Cloud:** AWS (EKS, Lambda), Apache Kafka, Docker
* **Seguridad:** Zero Trust Architecture, PCI-DSS 4.0, HSM Thales
